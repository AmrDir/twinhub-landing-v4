# خطة المرحلة الثانية: لوحة التحكم وربط قاعدة البيانات (Supabase + Google Auth)

## 🎯 الأهداف
1. تفعيل الدخول الآمن للوحة التحكم عبر Google Login فقط.
2. إنشاء نظام مسارات (Routing) لفصل الموقع العام عن لوحة التحكم الخاصة.
3. ربط نصوص وصور الموقع بقاعدة بيانات Supabase لتمكين التعديل الحي.
4. تجهيز المشروع للرفع النهائي على Netlify.

## 🛠️ الخطوات التنفيذية

### 1. إعداد بنية البرنامج (Infrastructure)
- **تثبيت المكتبات:** 
  `npm install react-router-dom @supabase/supabase-js`
- **إضافة نظام المسارات:** تحديث `main.tsx` لإضافة الـ Router.
- **إعداد العميل:** إنشاء `src/lib/supabase.ts` للاتصال بـ Supabase.

### 2. واجهة الدخول (The Login Gate)
- إنشاء صفحة `/login` تحتوى على زر "Sign in with Google".
- ربط عملية الدخول بـ Supabase Auth.
- **حماية المسارات (Route Guard):** منع أي شخص غير مسجل الدخول من الوصول لصفحة `/admin`.

### 3. لوحة التحكم (The Private Dashboard)
- **الواجهة:** تصميم لوحة تحكم بسيطة وسينمائية.
- **إدارة المحتوى:** إنشاء نماذج (Forms) لتعديل:
    - نصوص الـ Hero والـ Services.
    - روابط صور المعرض (Gallery).
    - أرقام التواصل وروابط التواصل الاجتماعي.
- **المزامنة:** التأكد من أن التحديث في اللوحة يظهر في الموقع فوراً.

### 4. الرفع على Netlify
- إعداد ملف `netlify.toml` للتعامل مع الـ Single Page Application (SPA).
- إعداد المتغيرات البيئية (Env Variables) في لوحة تحكم Netlify.

## 🔍 التحقق (Verification Plan)
- اختبار عملية الدخول بجوجل والتأكد من نجاحها.
- تجربة تعديل "نص" في لوحة التحكم والتأكد من ظهوره في الموقع.
- اختبار استقرار الموقع (Zero Error) بعد إضافة نظام المسارات.

## ⚠️ تنبيهات هامة
> [!WARNING]
> ستحتاج لتزويدي بـ `SUPABASE_URL` و `SUPABASE_ANON_KEY` لاحقاً لوضعها في ملف `.env` ليعمل الاتصال بشكل صحيح.
